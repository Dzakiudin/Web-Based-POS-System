=======================================================
  ⚡ POS System Pro Max v2.0.0 (Native Edition)
=======================================================

Aplikasi sistem kasir mandiri berperforma tinggi (Rust + React 19).

CARA MENJALANKAN DI PC (PILIH SALAH SATU):

1. MODE OFFLINE / LOKAL:
   - Klik 2x file "start.bat"
   - Server lokal otomatis aktif dan browser terbuka di:
     http://localhost:5000

2. MODE CLOUD / MULTI-DEVICE (HP ANDROID + PC):
   - Klik 2x file "start-cloud.bat"
   - Server lokal otomatis dibuka ke internet via Cloudflare Tunnel.
   - Akan muncul URL publik berformat:
     https://xxxx.trycloudflare.com
   - Buka aplikasi POS di HP Android Anda, klik "Atur Server / Cloud"
     pada halaman login, dan tempel URL tersebut.
   - HP dan PC kini terhubung secara realtime dari mana saja!
